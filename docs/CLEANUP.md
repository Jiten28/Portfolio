# Cleanup when replacing an older portfolio

Use the latest **source** archive for Git, not the built Netlify archive. Back up local changes first; keep `.git`.

## Safe to remove from the latest Vite site
- `public/cv-pages/`: obsolete CV images. The current viewer and asset check use only `public/Jiten_Kumar_CV.pdf`.
- `dist/`: generated build; regenerated by `npm run build`, not committed.
- `*.tsbuildinfo`: generated TypeScript cache, not committed.
- Downloaded release ZIPs, temporary logs, and duplicate backup folders (after keeping a backup elsewhere).
- `reference/`: optional original customization/unused-asset archive, not imported by the running site. Keep elsewhere if you want the originals.
- `docs/`: optional QA notes, cleanup notes, and logo concepts; not needed to run the site.

The unused `src/Assets/portrait.svg` has been moved to `reference/unused-assets/`.

## Keep
- All active files in the latest `src/` folder, including `src/pages/CVPage.tsx` (the webpage, not a CV image).
- `public/Jiten_Kumar_CV.pdf`, `public/projects/`, `public/work/`, favicon, share image, redirects, robots, sitemap.
- Root `index.html`, `package.json`, `package-lock.json`, `scripts/`, and build/configuration files.
- `tailwind.config.js` is explicitly referenced by `src/index.css`; do not remove it.
- `README.md`, `.gitignore`, and `.gitattributes` are recommended handoff/repository files.

## Avoid mixing releases
If extra old components or `src/bgpreview/` remain locally, they are not in the current active source release. Replace `src/` and `public/` with clean copies from the latest source archive instead of merging directories. Preserve any new local customization first. Originals are retained under `reference/`.

Do not restore old Create React App `public/index.html`, JavaScript app entries, or assets simply because Git lists deletions: this release replaces those with the Vite structure. Review the staged diff before committing.

Never commit `node_modules/`; removing it locally is optional and requires `npm ci` before building again.
